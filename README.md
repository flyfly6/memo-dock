# Memo Dock

Memo Dock keeps profile-wide Markdown notes, checklist todos, and code snippets in the VS Code sidebar.

## Development

- Press `F5` to build and open an Extension Development Host.
- Run `npm run typecheck`, `npm run lint`, and `npm test` for targeted checks.

Snippet code opens in the native VS Code editor. Markdown documents use a constrained BlockNote editor and are persisted as Markdown under the current profile's extension storage.
